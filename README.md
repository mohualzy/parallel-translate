# 双语对照翻译 (Parallel Translate)

把网页、PDF 和 YouTube 字幕翻成双语对照的浏览器扩展。模型由你自己选，云端 API 和本地模型都能用，请求直接发给你配置的服务，不经过任何中间服务器。

## 创新点

翻译好不好，模型只决定一部分，另一部分取决于模型拿到了什么、译文放回哪里、每一步花了多少钱。这个扩展的工程量主要在这几件事上。

### PDF：译文写回原版面

译文不是贴在原文上的一层文本框，而是和背景在同一个画面里。

- 渲染时拦下文字绘制，得到只有背景、图片和线条的底图，再按原段落的位置、颜色和字重写入译文。
- 公式和代码按原字体识别，作为不可拆分的整体原样保留。行内公式的分数线、根号跟着字形一起移动，行间公式随译文整块上移。
- 同一栏的段落依次排布，字号统一，中文比英文短出来的空间集中留在栏底。
- PDF 只在本机解析，发给模型的只有文字片段。

### YouTube 字幕：先通读全片，再逐批翻译

分批翻译省钱，但批首看不到前文，同一个人名前后容易译成两样。

- 字幕到手后先通读一遍，得到内容摘要和最多 12 条术语，之后每批都带上这些，再加前 4 条和后 3 条台词。
- 真正翻译的只有当前播放位置附近，只看几分钟就只付几分钟的钱。
- 通读不阻塞字幕。术语回来后，只重翻译法有冲突的条目。

### 音乐视频：用同步歌词替换听错的自动字幕

语音识别听不准演唱，模型把错的原文翻得再准也没用，所以这里换的是原文来源。

- 只有自动字幕的音乐视频，会到 LRCLIB 查同步歌词当原文。
- MV 和专辑版的时间轴不同。扩展把自动字幕里还算对的句子和歌词比对，每对相似的句子给一个时间差投票，3 秒窗口内得票最多的就是偏移，重复的副歌不影响结果。票数不够又对不上时长时就放弃歌词。
- 日语、中文、韩语、俄语的自动字幕里，完全没有该语言文字的条目会被直接丢弃，不为乱码付翻译费。

### 术语：长文前后一致，首屏不等

- 长文开启翻译时，术语抽取和正文翻译同时进行，首屏速度不变。术语回来后，只重翻原文命中术语、译文却没用该译法的段落。
- 术语表只把当批出现的条目发给模型，写多少条都不拖慢普通页面。
- 同形词可以带条件。写成 `Apple（指公司时）` 后，真实模型实测 "Apple released a new iPhone" 保留 Apple，"she ate an apple" 译为「苹果」。

### 每一次请求都算过账

| 做法 | 效果 |
|---|---|
| 逐字输出的内容等稳定 1 秒再翻 | 一句话从 6 次请求降到最多 2 次（E2E） |
| 网站规则跳过代码 | GitHub 代码文件从 2559 段降到 2 段（实测） |
| 预设关闭模型推理 | DeepSeek 同一批文本输出 token 减少约 75%（实测） |
| 漏段时对半拆开补翻 | 每批最多多 2 次请求，模型输出乱掉时不会变成逐段重发 |
| 只翻滚动到的内容，多段合批，缓存 30 天 | 不看的不花钱，重复访问不计费 |

### 不破坏网页

- 只追加自有元素，不移动、不包裹页面节点，避开和 React、Vue 等框架的冲突。仅译文模式靠 CSS 实现。
- 链接、粗体、行内代码用编号占位标签交给模型，译后按编号重建。点译文里的链接等于点原链接，单页应用的路由照常工作。
- 改动全局逻辑时用 `just sweep` 在十几个真实网站上做新旧对比。比如仅译文模式的一次修复，让 Wikipedia 的双语残留从 68 段降到 2 段，Kubernetes 文档从 23 段降到 0 段。

## 功能一览

- **双语对照**：译文插在每段原文下方，也可切换「仅译文」
- **悬停翻译**：鼠标停在段落上单按一下 Ctrl，只翻译这一段
- **划词翻译**：选中文字旁出现「译」按钮；单词给音标、释义和语境含义，句子给译文，逐字流式显示
- **悬浮球**：页面右侧一键开关翻译，可上下拖动，可按网站隐藏
- **输入框翻译**：在输入框里写中文，按 `Alt+I` 或在末尾连按三次空格，换成英文（可设置）后写回；选中一部分则只翻选中的；`Ctrl+Z` 撤销
- **PDF 双语阅读**：左原文、右译文并排，也可只看译文；译文可选中复制、`Ctrl+F` 查找，可加高亮或下划线（保存在本机）；可切换中文字体，可导出 PDF 和 Markdown 笔记
- **侧栏文本翻译**：在浏览器右侧侧栏里粘贴任意文字翻译，保留段落和列表；输入外文译成中文、输入中文自动译成英文；可临时切换服务和风格
- **YouTube 双语字幕**：打开播放器的 CC 字幕即显示原文 + 译文；自动字幕先合成整句再翻译；有人工字幕时优先使用，只有自动字幕时标注「自动字幕」，用了同步歌词时标注「歌词」
- **翻译风格**：通用、技术文档、学术论文、新闻、社交媒体、文学六种风格，按网站自动选择，也可以在弹窗里为当前网站指定
- **术语表**：指定专有名词的固定译法；弹窗里可以查看本文抽取的术语
- **动态页面**：无限滚动、SPA、AI 对话逐字输出、iframe、Web Components（Shadow DOM）
- **网站规则**：总是翻译 / 永不翻译 / 自定义不翻译区域
- **常见网站适配**：Hacker News 只翻标题和评论；GitHub 不翻代码、diff、文件列表和路径；X 不意译用户名和趋势。可在设置页关闭

## 模型支持

任何 OpenAI 兼容接口都能接入，预设里有 DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenRouter、Gemini、OpenAI、本地 Ollama 和 llama.cpp。

分段和占位协议的自动实测目前只覆盖 DeepSeek（`just e2e-live`）。其他服务协议兼容，但模型遵守协议的程度因模型而异；个别段落漏翻时会自动补翻，效果不好时可以调小「每次请求最多段落数」。

## 安装

需要 Node.js 24、[pnpm](https://pnpm.io) 和 [just](https://github.com/casey/just)。克隆仓库后，在目录里执行：

```bash
pnpm install
```

```bash
just build
```

构建结果在 `.output/chrome-mv3`。然后在浏览器中加载：

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `.output/chrome-mv3` 目录

已经打开的网页不用刷新：扩展装好后会自动注入。

更新代码后重新 `just build`，在扩展管理页点扩展卡片上的刷新按钮即可。已打开的页面会自动换上新版本，正在翻译的页面会保持翻译状态（YouTube 双语字幕除外，需要刷新视频页）。

支持 Chrome 和 Edge；在网页上自动打开 PDF 需要 Chrome 128 以上。Firefox 版可以构建（`just build-firefox`），但还没有完整测试。

## 配置翻译服务

首次安装会自动打开设置页：

1. 在「翻译服务」右侧选择预设（如 DeepSeek），点「添加」
2. 填入 API Key
3. 点「获取模型列表」，在模型输入框里选择模型（也可以直接手填）
4. 点「测试连接」，看到「连接成功」和译文示例后点「保存」

可以添加多个服务，在弹窗里随时切换。「高级选项」里可以调温度、并发数、超时，写额外的翻译要求（例如「API 名称保留英文」，叠加在网站的翻译风格之后），以及填写额外请求参数（JSON，合并进请求体）。

## 使用

| 操作 | 方式 |
|---|---|
| 翻译 / 还原整页 | `Alt+A`，或点工具栏图标 →「翻译此页面」，或右键菜单 |
| 立即翻译整页（不等滚动到） | `Alt+W` |
| 切换双语 / 仅译文 | 在弹窗里切换；也可在快捷键设置里给「切换双语对照 / 仅译文」绑定按键 |
| PDF 双语阅读 | 在设置里打开「在网页上打开 PDF 时直接进双语阅读器」后，点开的 PDF（包括 arXiv 等没有 .pdf 后缀的链接）直接进阅读器，阅读器里点「原文件」可用浏览器自带的查看器看；或打开 PDF 后点弹窗里的「用双语阅读器打开此 PDF」；或右键 PDF 链接「用双语阅读器打开 PDF」；本地文件拖进阅读器或点「打开本地文件」 |
| 导出 PDF | 阅读器工具栏「导出 PDF」：选「仅译文」或「双语并排」（左原文、右译文），没翻译的页会先翻译（有费用提示），强调一起导出；导出的是图片版，文字不能选中 |
| PDF 阅读位置 | 自动记住：再次打开同一篇 PDF（不管从哪个地址）回到上次读到的地方；缩放时视口停在原处 |
| 切换 PDF 译文的中文字体 | 阅读器工具栏「中文字体」：自动 / 宋体 / 黑体 / 楷体 / 仿宋；新装的字体先选「读取本机字体…」并允许授权，之后自动列出；也可「手动输入…」字体名。切换只重画，不重新翻译 |
| PDF 译文查找 / 复制 / 强调 | 阅读器里按 `Ctrl+F` 打开查找栏（可切换搜译文 / 原文，跨行的词也能找到，`Enter` / `Shift+Enter` 上下翻，`Esc` 关闭）；原文页也能拖选复制；在译文页上拖选文字，`Ctrl+C` 复制，或在弹出的工具条里选高亮颜色、下划线、复制；选中已强调的文字可「清除」；点工具栏「强调 N」打开强调面板，按页列出、点一条跳过去、单条删除或「全部清除」（会先确认），或导出 / 复制 Markdown（附原文对照） |
| 网页划词强调 | 选中文字（原文、译文都行），在弹出的工具条里选高亮颜色或下划线，选中已强调的部分可「清除」；只在当前页面有效，刷新即消失。可在设置里关掉「选中文字时显示强调按钮」 |
| 侧栏文本翻译 | `Alt+S`、弹窗里的「在侧栏翻译文本」，或选中文字后右键「在侧栏中翻译选中文字」；粘贴即翻译，手动输入停顿后自动翻译，`Ctrl+Enter` 立即翻译 |
| 输入框翻译 | 在输入框里按 `Alt+I`（有选中文字时只翻选中部分），或在内容末尾连按三次空格；目标语言在设置页「输入框翻译成」里改；`Ctrl+Z` 撤销 |
| YouTube 双语字幕 | 打开视频的 CC 字幕（点 CC 按钮或按 `c`），译文会显示在原文下方；关掉 CC 即恢复原生字幕 |
| 学习遮罩（译文模糊，悬停显示） | 在快捷键设置里给「切换学习遮罩」绑定按键 |
| 只翻译某一段 | 鼠标停在段落上，单按一下 `Ctrl`（再按一次收起）；按键可在设置里改 |
| 翻译失败重试 | 失败时页面顶部会提示原因；点击任一「翻译失败，点击重试」，本页所有失败的段落一起重试；也可以点弹窗里的「重试失败的 N 段」 |
| 修改快捷键 | 弹窗底部「修改快捷键」，或 `chrome://extensions/shortcuts` |

## 常见问题

- **快捷键没反应**：如果同时装着沉浸式翻译，`Alt+A` / `Alt+W` / `Alt+I` / `Alt+S` 都会冲突，后装的扩展拿不到默认按键；在 `chrome://extensions/shortcuts` 里给其中一个改键。
- **输入框翻译写不进去**：少数自定义编辑器不接受程序写入，这时译文会放进剪贴板，手动粘贴即可。密码框、邮箱等输入框不会被翻译。
- **PDF 阅读器打不开本地 file:// 地址 / 本地 PDF 没有自动进阅读器**：在扩展详情页打开「允许访问文件网址」，或直接把文件拖进阅读器。本地 PDF 自动打开时浏览器自带的查看器会先闪一下，属正常。扫描版 PDF 没有文字层，无法翻译。
- **某些页面无法翻译**：浏览器内置页面（`chrome://`）、扩展商店不允许扩展运行；本地文件（`file://`）需要在扩展详情里打开「允许访问文件网址」。
- **按钮、导航没有被翻译**：双语对照模式默认跳过短的界面文字和按钮，避免撑乱布局；切换到「仅译文」模式会原地翻译它们（按钮照常可点）。也可以悬停按 Ctrl 单独翻译，或在设置里关闭「双语对照时跳过…」。
- **Ollama 返回 403**：Ollama 默认拒绝来自扩展的请求，启动前设置环境变量 `OLLAMA_ORIGINS=chrome-extension://*`。
- **本地 llama.cpp（llama-server）**：选「llama.cpp（本地）」预设，地址 `http://127.0.0.1:8080/v1`，并发数默认 2，需与启动参数 `--parallel` 一致；服务端设了 `--api-key` 时把同一个密钥填进 API Key。Qwen3.5 等模型默认会思考，在服务端用 `--reasoning off` 关闭。
- **DeepSeek**：当前模型是 `deepseek-flash` / `deepseek-v4-pro`，默认会推理。预设已自动填好 `{"thinking": {"type": "disabled"}}`，实测输出 token 减少约 75%；手动添加时记得加上。
- **推理模型太慢、太贵**：在「高级选项 → 额外请求参数」里关闭思考，参数名因服务而异，例如通义 `{"enable_thinking": false}`、Ollama `{"think": false}`、OpenAI `{"reasoning_effort": "minimal"}`，以服务商文档为准。
- **偶尔有段落漏翻**：弱模型可能漏掉批量中的个别段落，扩展会自动补翻；仍失败时点击重试，或在设置里调小「每次请求最多段落数」。
- **费用**：只有滚动到的段落才会请求；已翻译内容缓存在本机，重复访问不计费。

## 隐私

- API Key 只保存在本机浏览器（`chrome.storage.local`），不会同步，导出设置时默认不包含；模型请求只从扩展后台发出。
- 页面文本、字幕和 PDF 的文字片段只发给你配置的翻译服务。用本地模型时，这些内容不离开本机。
- PDF 文件只在本机解析，不上传。
- 唯一的额外请求：只有自动字幕的音乐视频，会把歌手和歌名发给 [lrclib.net](https://lrclib.net) 查歌词，不发视频 ID、页面地址或其他数据。可在设置里关闭。
