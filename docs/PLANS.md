# PLANS — 路线图

目标：完整的网页翻译体验，翻译质量取决于用户自选模型。
原则：先把「读网页」这条主路径做到好用，再扩展到字幕/PDF 等场景。

## Phase 1 — MVP（v0.1，2026-10-22 完成）

- [x] 工程骨架：WXT + TS + Vitest + Playwright，`just check` / `just e2e`
- [x] 翻译服务：OpenAI 兼容协议（覆盖 OpenAI / DeepSeek / 通义 / Kimi / 智谱 / 硅基流动 / OpenRouter / Gemini / Ollama），多服务配置、测试连接、拉取模型列表
- [x] 后台：流式请求、超时、429/5xx 重试、按服务并发限制、Service Worker 保活
- [x] 批量翻译：多段合并为一次请求（`<s id>` 分段协议），解析失败自动逐段兜底
- [x] 翻译缓存（IndexedDB，按 服务+模型+目标语言+提示词+原文 作键）
- [x] 段落识别：块级元素 + 行内片段（inline run），排除代码/输入框/编辑器/读屏隐藏文字
- [x] 默认跳过按钮、导航等短界面文字（可关闭；悬停翻译不受限）
- [x] 懒翻译：只翻译进入视口附近的段落（IntersectionObserver）
- [x] 动态内容：MutationObserver 处理 SPA / 无限滚动；框架重渲染后自动补回译文
- [x] 富文本保留：译文中保留链接、加粗、行内代码
- [x] 显示：双语对照 / 仅译文；译文样式（无、虚线、下划线、高亮、弱化、模糊）
- [x] 悬停 + 按键翻译单段
- [x] 快捷键 Alt+A 翻译/还原、Alt+W 切换显示模式；右键菜单
- [x] 网站规则：总是翻译 / 永不翻译；可选「外文页面自动翻译」
- [x] 弹窗 + 设置页；设置导入/导出（默认不含 Key）

### 待验证

- [x] 用真实模型 API 实测：DeepSeek 已验证（`just e2e-live`，见 DECISIONS D18–D20）；其他服务商尚未实测
- [ ] 设置导入/导出、右键菜单、快捷键本身（E2E 直接发消息，没有覆盖按键注册）手动验证
