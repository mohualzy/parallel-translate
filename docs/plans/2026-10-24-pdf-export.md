# 导出译文 PDF / 双语 PDF — 实现计划

目标：阅读器里一键导出「仅译文」或「双语并排」（左原文、右译文）的 PDF，用于存档、离线读、打印、分享；强调一并导出。决策见 DECISIONS D63。

## 方案

- 每页离屏重新渲染（固定 2 倍清晰度，和当前缩放、视口无关），画好译文和强调后转成 JPEG，立即释放画布。
- 还没翻译的页先补翻（和阅读时同一条翻译路径、同一份缓存），导出前提示剩余页数和费用。
- 手写最小 PDF 写入器：JPEG 直接作为 `DCTDecode` 图片嵌入，不解码；页面尺寸用原 PDF 的点数，双语并排页宽 = 两页 + 间隔。标题写进文档信息（UTF-16BE）。
- 导出的 PDF 是图片，文字不能选中（要能选中需另写一层隐藏文字，工作量翻倍，暂不做）。
