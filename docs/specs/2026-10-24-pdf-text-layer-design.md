# PDF 译文页：选中复制、Ctrl+F 搜索、划词强调 — 设计

## 目标

- 译文页上的文字可以用鼠标选中、`Ctrl+C` 复制，复制出来按段落分行。
- `Ctrl+F` 能搜到译文页上的文字（译文和保留原文的部分：人名、公式、未翻译的段落），跨行的词也能找到。
- 选中文字后弹出小工具条：四种高亮颜色、下划线、复制、清除。强调按文档保存，下次打开同一个 PDF 还在；换字体、缩放、重排后仍落在原来的文字上。

不做：原文页的选中 / 搜索（pdf.js 自带的文本层可以以后加）；导出带强调的 PDF；强调的笔记 / 批注。

## 方案

### 1. 页面文字几何（PageText）

译文页上每个块（翻译过的、保留原文的）都整理成一份几何描述，文字层和强调绘制都从它派生，两边位置一致：

- `text`：块的「显示文本」。翻译块 = 全部 token 按顺序拼接（空白为一个空格，公式原子用原文字符）；保留原文的块 = 各行文本项拼接，行间、项间按间隙补空格。
  - 显示文本**和断行无关**：换字体、缩放后断行变了，偏移量不变，强调不会错位。断行时被丢掉的行末空格仍在文本里，只是没有位置。
- `pieces`：每个 token / 文本项在画布上的位置（`start`、`end` 偏移，`x`、`w`、基线、字号、行号）。
- `key`：块原文 + 在本页出现的序号（同一页重复的页眉也能区分）。
- 平移过的公式区域（D54）里的保留块，位置加上平移量。

纯计算放 `src/lib/pdf/page-text.ts`，可单测；翻译块的 token 位置在 `pdf/draw.ts` 排版时产出（`drawTranslatedPage` 返回 PageText）。

### 2. 文字层（选中、复制、搜索）

- 译文画布上叠一层透明文字（`color: transparent`，和 pdf.js 的文本层同一思路）：每个块一组、每行一个 `span`，绝对定位到该行的位置，`scaleX` 拉伸到画出来的宽度。行内字符位置是近似的，但选区两端和画面基本对齐。
- 行 `span` 的文字 = 显示文本里从本行起点到下一行起点的那一段，所以 DOM 文本和显示文本逐字相同，选区偏移可以直接换算成块内偏移。块末尾放 `<br>`，复制时按段落分行。
- 位置用百分比、字号用 `calc(var(--w) * 比例)`：缩放后不用重建也对得上。
- 页面离视口很远时只释放画布、保留文字层，选中复制不受影响。
- **块按阅读顺序排列**：浏览器扩展选区按 DOM 顺序走。版面分析按纵坐标建块，两栏的段落是交错的（左一、右一、左二……），从左栏一段拖到下一段会把夹在中间的右栏段落一起选上（用户实测反馈）。文字层改按「栏优先」排：找一条两侧都有块、左右并排的栏缝，跨过它的块（通栏标题、图注、脚注、页码）把页面切成上下几段，每段先读完左栏再读右栏，栏内递归（四列作者栏）。查找结果也按这个顺序。
  - 拖到空白处不会乱跳（真实论文实测：段落空隙、栏缝、左边距都停在附近的字上；拖到右边距会延伸进右栏，因为鼠标已贴着右栏），所以没有加 pdf.js 的 endOfContent 补丁。

### 3. 查找（接管 Ctrl+F）

浏览器原生查找不能跨绝对定位的行匹配（实测：标题折成「…Bilingual 」「Reading」两行后搜不到「Bilingual Reading」）。中文可以在任意字之间换行，「注意力」常被拆成「注意｜力」，原生查找漏得很多。所以阅读器里按 `Ctrl+F` 打开自己的查找栏：

- 在各页的显示文本里搜（和断行无关，跨行能找到；不跨块），不区分大小写。范围是看过的页：显示文本在重画时记下，画布释放后仍保留；从没滚到过的页没有译文，也就搜不到（和翻译的按需策略一致）。
- 命中处在译文页上叠半透明框（位置来自同一份文字几何），当前命中用橙色，滚动到它；`Enter` / `Shift+Enter` 下一个 / 上一个，`Esc` 关闭。显示「第几个 / 共几个」。
- 译文陆续到达、换字体重画后，命中结果随之更新。
- 透明文字层仍在，从浏览器菜单打开的原生查找对不跨行的文字照样能用。

### 4. 划词强调

- **工具条**：在文字层里松开鼠标、选区不为空时，在选区末尾附近显示：黄 / 绿 / 蓝 / 粉高亮、下划线、复制、清除。点别处或滚动时隐藏。
- **模型**：`{ id, page, key, start, end, quote, style }`，一个块一条；跨块、跨页的选区拆成多条。新强调覆盖同块里重叠的旧强调（旧的被切掉重叠部分）；「清除」去掉选区覆盖的部分。纯逻辑放 `src/lib/pdf/highlights.ts`。
- **定位**：重画时先看 `text.slice(start, end) === quote`；不等时在块文本里找 `quote`（只出现一次才用）；找不到就暂不显示，但不删除（换回原来的翻译风格又能显示）。
- **绘制**：画在译文画布上，所有内容画完后用 `multiply` 混合叠一层颜色：白底变色、黑字不受影响，不用关心先后顺序。下划线直接画在基线下方。
- **保存**：`chrome.storage.local` 的 `pdfHighlights:<文档指纹>`（pdf.js 的 `fingerprints[0]`，同一文件不管从哪个地址打开都一样）。只存在本机，不同步、不上传（规则 7）。

### 5. 强调面板（D59）

- 工具栏「强调 N」打开右侧面板：按页码、页内阅读顺序列出强调，点一条滚过去（这一页看过就定位到行，否则滚到页首），可单条删除。
- 导出 Markdown（下载 `<标题>-强调.md` 或复制）：按页分节，`==高亮==`、`<u>下划线</u>`，非黄色注明颜色；同一段的强调列在一起，后面附该段原文（本次看过的页才有）。

## 边界

- 透明文字用一种字体按行拉伸，行内英文单词的选区边缘可能偏几个像素。
- 栏缝识别是启发式的：版面不规则（图文混排、三栏以上且宽度不一）时阅读顺序可能不理想，拖选会多选到别的段落。
- 「仅原文」模式下译文页隐藏，查找栏仍能计数，但看不到命中框。
- 只搜译文页，不搜左边的原文页。
- Type3 字体的页面没有译文，文字层只有原文。
